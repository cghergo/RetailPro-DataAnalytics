# 📊 RetailPro – Proyecto de Data Analytics

## Descripción del proyecto

RetailPro es un proyecto integral de Data Analytics desarrollado como parte de un programa de formación profesional. El objetivo es transformar datos comerciales en información confiable para apoyar la toma de decisiones mediante procesos de extracción, transformación, modelado y visualización.

A lo largo del proyecto se aplican técnicas de SQL, Power Query, Power BI y DAX para construir un flujo completo de análisis de datos, desde la preparación de la información hasta el desarrollo de dashboards ejecutivos.

---

# Objetivos

- Diseñar una base de datos relacional.
- Resolver consultas de negocio mediante SQL.
- Aplicar procesos ETL utilizando Power Query.
- Construir un modelo de datos siguiendo buenas prácticas.
- Crear medidas DAX para el análisis de indicadores.
- Diseñar dashboards ejecutivos en Power BI.
- Documentar cada etapa del proyecto utilizando GitHub.

# Flujo del proyecto

El proyecto se desarrolla siguiendo un proceso completo de análisis de datos:

1. Definición del problema de negocio.
2. Diseño del modelo de datos.
3. Desarrollo de consultas SQL.
4. Limpieza y transformación de datos mediante Power Query.
5. Construcción del modelo relacional en Power BI.
6. Desarrollo de medidas DAX.
7. Diseño de dashboards ejecutivos.
8. Documentación técnica del proyecto.

---

# Cómo utilizar el proyecto

## SQL

1. Crear o restaurar la base de datos **Ventas_Tech_DB**.
2. Ejecutar los scripts SQL respetando el orden de los módulos.

## Power BI

1. Abrir el archivo `.pbix` correspondiente.
2. Actualizar el origen de datos si fuera necesario.
3. Revisar el modelo de datos.
4. Explorar los dashboards y medidas DAX.
