# RetailPro – Proyecto de Data Analytics

## Descripción

RetailPro es un proyecto académico de análisis de datos cuyo objetivo es transformar datos comerciales en información útil para la toma de decisiones mediante procesos de SQL, Power Query y Power BI.

Durante el desarrollo del proyecto se construyó una base de datos relacional, se realizaron procesos de limpieza y transformación de datos (ETL), se diseñó un modelo dimensional y se desarrollaron medidas DAX para el análisis de indicadores de negocio.

---

## Objetivos

- Diseñar una base de datos relacional.
- Realizar consultas SQL para responder preguntas de negocio.
- Limpiar y transformar datos utilizando Power Query.
- Construir un modelo de datos en Power BI.
- Crear indicadores (KPIs) y medidas DAX.
- Desarrollar dashboards para apoyar la toma de decisiones.

---

## Herramientas utilizadas

- SQL Server

- Power Query
- DAX

## Cómo ejecutar el proyecto

1. Crear o restaurar la base de datos **Ventas_Tech_DB**.
2. Ejecutar los scripts SQL respetando el orden de los módulos.
3. Abrir el archivo Power BI (.pbix).
4. Actualizar el origen de datos si fuera necesario.
5. Explorar el modelo de datos y los dashboards desarrollados.
