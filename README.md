# RetailPro - Proyecto de Data Analytics

Este repositorio contiene el desarrollo del proyecto final del curso de Data Analytics, basado en el caso de negocio de **RetailPro**, una empresa distribuidora de tecnología.

## Objetivo

Diseñar e implementar una solución completa de análisis de datos, comenzando por el modelo relacional en SQL y finalizando con un dashboard ejecutivo en Power BI.

## Estructura del proyecto

- **Modulo_01:** Definición del problema de negocio, KPIs y boceto del dashboard.
- **Modulo_02:** Modelo relacional (ER) y normalización.
- **Modulo_03:** Script SQL de creación de la base de datos, tablas, restricciones e inserción de datos.
- **Módulos siguientes:** Consultas SQL, modelado de datos, Power BI y dashboard final.

## Tecnologías utilizadas

- SQL Server
- SQL Server Management Studio (SSMS)
- GitHub
- Power BI (próximamente)
