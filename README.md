# RetailPro - Proyecto de Data Analytics

Este repositorio contiene el desarrollo del proyecto final del curso de Data Analytics, basado en el caso de negocio de **RetailPro**, una empresa distribuidora de tecnología.

## Objetivo

Diseñar e implementar una solución completa de análisis de datos, comenzando por el modelo relacional en SQL y finalizando con un dashboard ejecutivo en Power BI.


## Tecnologías utilizadas

- SQL Server
- SQL Server Management Studio (SSMS)
- GitHub
- Power BI
